Это мой первый опыт разработки плагинов Minecraft.

это плагин на авторизацию нацеленный на использование на слабых серверах или для тех кто любит легковесные плагины без сложных конфигов

функционал:
1. Базовая регистрация и авторизация + шифрование через BCrypt
2. поддержка GeyserMC
3. автоматический вход по IP и сброс пароля
4. SQlite бд
